# Mini World ID Studio 2.0.0

La v2 introduce un Centro de datos del juego completamente local. El usuario elige la carpeta que quiere analizar y Studio extrae únicamente metadatos técnicos: nombres de API, eventos, IDs, conteos y procedencia relativa.

Los campos de jugador en los modos Básico e Intermedio conservan todas sus opciones. Cuando una referencia no existe en el evento actual, Studio la marca como no disponible en vez de ocultarla y dejar únicamente `nil`.

## Seguridad y propiedad intelectual

- No incluye ni descarga repositorios decompilados.
- No ejecuta herramientas, scripts ni Lua encontrado.
- No lee DLL, EXE, PKG, WSC, mapas, audio, texturas o modelos.
- No conserva rutas absolutas ni cuerpos de código en el informe exportable.
- Todo símbolo desconocido queda pendiente de revisión y no se convierte automáticamente en una acción.

## Límites

- 25.000 archivos encontrados por análisis.
- 4 MB por archivo de texto.
- 64 MB leídos en total.
- Profundidad máxima de 9 carpetas.
- Enlaces simbólicos ignorados.

# Mini World ID Studio 2.0.0 — English

Version 2 introduces a fully local Game Data Center. The user selects the folder to scan, and Studio extracts metadata only: API names, events, IDs, counters, and relative provenance.

Player fields in Basic and Intermediate modes keep all choices visible. When the current event does not provide a reference, Studio labels it as unavailable instead of hiding it and leaving only `nil`.

## Security and intellectual property

- Does not bundle or download decompiled repositories.
- Does not execute discovered tools, scripts, or Lua.
- Does not read DLL, EXE, PKG, WSC, maps, audio, textures, or models.
- Does not retain absolute paths or code bodies in exported reports.
- Unknown symbols stay pending review and never become generator actions automatically.

Limits are 25,000 discovered files, 4 MB per text file, 64 MB total read, nine directory levels, and no symbolic links.
