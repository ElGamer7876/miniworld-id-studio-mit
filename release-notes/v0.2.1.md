# Mini World ID Studio MIT 0.2.1

Primera publicación open source recomendada para Windows x64.

## Cambios principales

- Corrige el salto de activadores hacia `0,0` durante el arrastre.
- Rechaza saltos anómalos enviados por WebView.
- Usa desplazamientos incrementales y controles adaptados a gestos de puntero.
- Incluye mapa visual, editor de bloques, Lua, condiciones y variables.
- Guarda proyectos localmente y exporta `.mwstudio` y `.lua`.
- Analiza Lua como texto y nunca lo ejecuta.
- No contiene HTTP, login, cookies, analíticas, telemetría ni fingerprint.

## Descargas

- `setup.exe`: instalador NSIS para Windows x64.
- `portable.exe`: ejecutable portable para Windows x64.

Windows puede mostrar SmartScreen porque los binarios todavía no tienen firma de editor comercial.
