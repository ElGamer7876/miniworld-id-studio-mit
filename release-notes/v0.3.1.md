# Mini World ID Studio 0.3.1

- Canal: `stable`
- Formato de proyecto: `2` (sin cambios)
- Versión anterior: `0.3.0`

## Cambios

- La edición conectada puede recuperar el mismo token cuando una respuesta de
  autorización se pierde y el mismo cliente repite el canje durante su vigencia.
- Cerrar la ventana de cuenta cancela correctamente la espera de autorización.
- Los mensajes distinguen una solicitud rechazada, vencida o consumida desde
  otro cliente.
- La página oficial de Studio incorpora una introducción visual adaptable.
- La edición MIT continúa sin cliente HTTP, login, cookies ni telemetría.

## Seguridad

El reintento del canje está limitado al mismo código aleatorio, dirección y
agente de la aplicación, y solo funciona durante la vigencia original. El token
se deriva con HMAC usando un secreto del servidor y nunca se guarda en claro.

## Problemas conocidos

- La autorización conectada requiere que la API corregida esté desplegada en
  `miniworld.id`.
- Los binarios de Windows todavía no están firmados con un certificado público.

## Recuperación

La versión 0.3.0 permanece disponible. Comprueba cada descarga con
`SHA256SUMS.txt` antes de instalarla.
