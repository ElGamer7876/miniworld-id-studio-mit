# Mini World ID Studio 1.1.0 Beta 2

## Español

Esta beta completa la localización funcional Español / English del Studio. Traduce todas las vistas principales, eventos, nombres y frases de acciones Mini World, parámetros, opciones seguras, diagnósticos y recuperación local.

El cambio de idioma es persistente y no modifica Lua, IDs técnicos, títulos, nombres de activadores ni valores escritos por el usuario.

Incluye instalador y versión portable para Windows x64. Es un prerelease de prueba y no reemplaza Stable.

## English

This beta completes the Studio's functional Spanish / English localization. It covers every main view, events, Mini World action names and phrases, parameters, safe choices, diagnostics, and local recovery.

The language preference persists and does not alter Lua, technical IDs, project titles, trigger names, or user-entered values.

Windows x64 installer and portable builds are included. This is a testing prerelease and does not replace Stable.
