# Mini World ID Studio MIT 0.1.0

Archivo histórico de la primera versión local para Windows x64.

- Editor visual de activadores y mapa.
- Condiciones, variables y acciones.
- Conversión entre bloques y Lua.
- Proyectos locales y exportación `.lua`.
- Sin red, login, analíticas ni telemetría.

Esta publicación conserva la última compilación corregida que llevaba el número 0.1.0. El repositorio se abrió públicamente en 0.2.1, por lo que la etiqueta histórica apunta al primer commit público disponible. Se recomienda instalar 0.2.1 o posterior.
