# Mini World ID Studio MIT 0.2.3

Corrección enfocada exclusivamente en el movimiento de activadores.

- El activador conserva su posición al soltarlo.
- Cada activador guarda sus propias coordenadas `x` y `y` inmediatamente.
- El lienzo no se reconstruye al finalizar el arrastre.
- Se evita el comportamiento inestable de Pointer Events observado en WebView2.
