# Mini World ID Studio 0.3.0

Esta versión transforma el catálogo de acciones en bloques configurables con frases legibles y un valor independiente para cada argumento.

## Cambios principales

- 52 acciones con parámetros, valores iniciales y cadenas de uso.
- Acciones completas de interfaz: abrir, cerrar, texto, textura, tamaño, fuente, color, visibilidad, giro, transparencia, estado, posición, escala e iconos.
- Valores contextuales como `e.eventobjid`, `e.x`, `e.y` y `e.z`.
- Resultados Lua sugeridos para APIs que devuelven valores.
- Editor avanzado compatible con expresiones, tablas y cadenas con comas.
- Pruebas automáticas de generación Lua para cada acción.

Incluye la edición conectada y la edición MIT local en formato instalable y portable para Windows x64.
