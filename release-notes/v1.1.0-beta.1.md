# Mini World ID Studio 1.1.0 Beta 1

## Español

- Selector persistente Español / English.
- Opciones contextuales para jugador, atributos, booleanos y estados en Básico e Intermedio.
- Los valores libres siguen siendo editables y reciben sugerencias del evento y variables.
- Las llamadas nuevas evitan referencias que el evento activo no proporciona.
- Incluye las mejoras acumuladas de simulación, bloques anidados, portapapeles, recuperación, búsqueda, comandos y métricas.

Esta versión es un **prerelease** y no reemplaza una versión estable.

## English

- Persistent Spanish / English language selector.
- Context-aware player, attribute, boolean, and state choices in Basic and Intermediate modes.
- Free-form values remain editable and receive event-field and variable suggestions.
- New calls avoid references that are unavailable in the active event.
- Includes the accumulated simulator, nested-block, clipboard, recovery, search, command-palette, and metrics improvements.

This build is a **prerelease** and does not replace a stable version.
