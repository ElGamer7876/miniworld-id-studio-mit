# Mini World ID Studio 1.1.0 Beta 3

## Español

Beta 3 incorpora respaldo completo del espacio de trabajo: proyectos, preferencias y plantillas locales se guardan en un archivo validado de hasta 16 MB. Restaurar siempre añade copias y remapea IDs en conflicto, sin sustituir proyectos actuales. Los puntos de recuperación se excluyen para mantener pequeño el respaldo.

El autoguardado ahora se ejecuta en orden, muestra Guardando o Guardado y conserva cualquier error visible con un botón para reintentar. También se añadió una guía bilingüe de atajos accesible desde la barra, `Ctrl+/` o la paleta de comandos.

## English

Beta 3 adds full workspace backups: projects, preferences, and local templates are stored in a validated file up to 16 MB. Restore always adds copies and remaps conflicting IDs without replacing current projects. Recovery points are excluded to keep backups small.

Autosave is now serialized, exposes Saving and Saved states, and keeps failures visible with an explicit retry button. A bilingual shortcut guide is available from the toolbar, `Ctrl+/`, or the command palette.

Windows x64 installer and portable builds are included. This remains a testing prerelease.
